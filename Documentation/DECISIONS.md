# Decisions Log

Engineering and product decisions with rationale. Product decisions marked **(user)** were confirmed by the project owner.

| ID | Date | Decision | Rationale |
|---|---|---|---|
| D-001 | 2026-11-04 | **Name: ABC Wonderworld (user).** The repository folder is `abcwonderland`; the request said "ABC Wonderland" but both specs say Wonderworld. | Confirmed by the owner. |
| D-002 | 2026-11-04 | Single explicit composition root `GameServices`, built by `ApplicationBootstrapper` in a fixed order. Scene controllers read it in `Start()`; `EnsureBooted()` makes any scene playable alone. | Avoids hidden execution-order dependencies and a web of singletons while keeping scenes testable. Services themselves are plain classes with constructor dependencies (testable without Unity). |
| D-003 | 2026-11-04 | Unity project in `UnityProject/` with docs/tools at repo root (master prompt §4). Created from the Unity 6 URP template `3d-cross-platform 17.0.14`; unused template packages removed (collab, multiplayer center, visual scripting, AI navigation, timeline, Rider). | Matches required structure; minimal dependencies. |
| D-004 | 2026-11-04 | Save = versioned local JSON (`JsonUtility`) behind `ISaveRepository`; write tmp → backup → replace; read main → tmp → backup → fresh; unreadable files preserved as `save.corrupt-*.json`; newer-version saves preserved untouched. | No query needs that justify SQLite; atomic and recoverable; tested (corruption, interrupted write, write failure, future version, migration). |
| D-005 | 2026-11-04 | **Dev package ID `com.nocvault.abcwonderworld.dev` (user).** | Owner confirmed a marked development ID until the release namespace is decided. |
| D-006 | 2026-11-04 | Missing audio never blocks play: `AudioService` logs a placeholder event once and inserts a short silent gap so voice-sequenced flows still advance. | Master prompt §5/§13. |
| D-007 | 2026-11-04 | **Phonics model (pending expert review).** General American; one beginner sound per letter: short vowels (/æ ɛ ɪ ɑ ʌ/), hard C /k/, hard G /g/, Q as /kw/ with "qu", X as /ks/ heard at the END of words (fox). Words that contain the letter but not the beginner sound (giraffe, ice cream, orange, owl, unicorn, xylophone, x-ray, fox) are flagged `startsWithSound=false` and never used to teach the initial sound. | GDD §8.2, master prompt §8. Requires review by an early-literacy specialist before release. |
| D-008 | 2026-11-04 | Characters animate through `ICharacterAnimator`. Placeholder cast uses `ProceduralCharacterAnimator` (code-driven idle/blink/greet/happy/celebrate/surprised/interact/dance/talk). Rigged production models should implement the same interface with an Animator Controller (parameters hashed in one class). | Procedural placeholder meshes have no skeleton; the interface keeps gameplay independent of the animation technology (master prompt §11 "clearly justified alternative"). |
| D-009 | 2026-11-04 | One stroke library (`LetterStrokeLibrary`) drives tracing paths, on-screen glyphs (`GlyphGraphic`) and 3D character bodies. Ball-and-stick manuscript, single-storey a/g. | Letters children see always match the forms they trace. Stroke order is provisional pending review. |
| D-010 | 2026-11-04 | **Placeholder pictures: Noto Emoji PNGs (user approved download).** 7 words without emoji are drawn in code (igloo, jam, lamp, quilt, xylophone, zipper, zoo). Yak uses a water-buffalo emoji and is flagged MISMATCH. | Recognisable, polished, permissive licence (README says images Apache-2.0; root LICENSE file is OFL-1.1 — both allow commercial use; confirm in legal review). |
| D-011 | 2026-11-04 | **Provisional voice: offline Kokoro TTS (Apache-2.0) (user approved).** Narrator `af_heart`; character intros rotate 5 American voices; isolated phonemes synthesised from IPA. All clips marked Provisional. | Makes the game voice-led from day one. Must be replaced by recorded voice; phonemes especially. |
| D-012 | 2026-11-04 | No AudioMixer asset: per-channel volumes, mute, music toggle and ducking are applied by `AudioService` on dedicated AudioSources. | AudioMixer assets cannot be created reliably from batch-mode code; behaviour required by §13 is equivalent. Revisit if a sound designer needs mixer effects. |
| D-013 | 2026-11-04 | Activities are uGUI over a themed 3D stage with the 3D character. World/home/free play are 3D with tappable props (PhysicsRaycaster + EventSystem gives touch/mouse parity). | Large, reliable, accessible touch targets; consistent input stack; 3D toy-world presentation. |
| D-014 | 2026-11-04 | Adventure archetypes are reusable templates configured per letter. All 12 implemented (TapCollect, PopTarget, FindHidden, Fill, DragToTarget, PlaceParts, MatchPairs, DragCollect, PathSteps, Pattern, Music, Swipe). Every drag has a tap alternative; MatchPairs uses select-then-tap from Discoverer level and shape marks so colour is never the only cue. | GDD §6.4, §15. |
| D-015 | 2026-11-04 | Parent gate: 2-second hold on a corner lock, then "Tap <number word>, then <number word>" with shuffled digits; a wrong tap issues a new challenge. | Reading number words + two-step instruction is beyond the 2–5 audience; not a single arithmetic question (master prompt §15). |
| D-016 | 2026-11-04 | "Showing Recognition" = ≥3 unassisted first-try correct selections across ≥2 sessions, and unassisted successes ≥ incorrect choices. Assisted/retried correct answers are recorded separately. | Conservative; a single correct answer is never evidence (GDD §10.3). |
| D-017 | 2026-11-04 | Adaptive difficulty: level starts from the parent profile; 4 consecutive easy rounds → +1; 2 consecutive struggling rounds → −1; parents can disable. Find the Letter choices 2 / 3–4 / 5–6 by level. | Transparent, gradual, reversible (GDD §2.2, §6.3). |
| D-018 | 2026-11-04 | Android: IL2CPP, ARM64 + ARMv7, min API 25, target auto, Vulkan + GLES3 with PowerVR denied Vulkan. | Reuses a fix verified on Little Burger World (PowerVR GE8xxx crash with Vulkan pipeline cache). |
| D-019 | 2026-11-04 | Graphics quality Auto/Low/Medium/High. Auto: Low if ≤3.5 GB RAM, PowerVR GPU or ≤4 cores (Low = no shadows, no MSAA, 0.8 render scale, 30 fps); High if ≥7.8 GB RAM; else Medium. Parent override in Settings (additive save field, defaults to Auto). | Master prompt §17; keeps budget phones (Redmi) smooth and flagships sharp. |
| D-020 | 2026-11-04 | Android back button/gesture: ignored inside activities and on Home (never quits, never exits an activity by accident); goes back one level elsewhere; closes the Parent Zone if open. | Toddlers trigger edge-swipe back constantly. |
| D-021 | 2026-11-04 | ABC sing-along: traditional public-domain melody synthesised at runtime from `AbcSong` timing data; provisional TTS letter names scheduled sample-accurately with `PlayScheduled`, so highlighting is in sync. Replace with an original sung recording + timing file. | GDD §6.6 (no unlicensed recordings). |
| D-022 | 2026-11-04 | **Owner chose to keep the GitHub repo public**; test APKs are published as GitHub Releases. | Easy direct download on test phones. |
| D-023 | 2026-11-05 | One finger at a time via `Input.PointerGate`: the first gameplay pointer (button press, drag, tracing touch) claims the gate; other pointers are ignored until it lifts; the gate frees itself whenever nothing touches the screen. The press-and-hold Home exit is deliberately not gated. Replaces `Input.multiTouchEnabled`, which has no effect on the Input System UI module. | Bug sweep: resting palms / second hands could drag two pieces, end a tracing stroke or answer twice. |
| D-024 | 2026-11-05 | Lifetime play time accumulates directly into the save (whole seconds), independent of the break-reminder timer; scenes framed for 16:9 keep their horizontal framing on narrower screens (`KeepHorizontalFraming`), and wide panels shrink to fit (`ScaleToFit`). Screen stays awake during play and returns to the system timeout after 5 idle minutes. | Bug sweep findings (play time was overwritten on launch; 4:3 tablets cropped edge characters and Parent Zone; screens dimmed mid-song). |
