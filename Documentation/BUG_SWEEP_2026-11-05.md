# Bug sweep — 2026-11-05

Method: 5 finder agents (core activities, adventures + UI, flow/screens/input/parent, data/learning/audio, Android/render/editor), each followed by an adversarial verifier. 42 findings reported, 40 confirmed, 2 refuted. All confirmed findings fixed (duplicates merged).

Verification after fixes: `Tools/setup.sh` 0 errors; EditMode 259/259 (7 new regression tests); PlayMode 29/29; AutoPilot 0 failures, 0 errors, 0 missing scripts. **Not yet verified on a physical device.**

## Found during verification (missed by the sweep)

- **Character prefabs had missing scripts** — `ProceduralCharacterAnimator` (in `CharacterAnimation.cs`) and `Bob` (in `CharacterFactory.cs`) lived in files not named after the class, so Unity could not serialize them into the generated prefabs. Every character in v0.1.0 was static (no blink/talk/dance/celebrate). Fixed by moving each into its own file; `CatalogTests.CharacterPrefabsHaveNoMissingScriptsAndCanAnimate` guards it.
