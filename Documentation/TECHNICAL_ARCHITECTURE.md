# Technical Architecture

Unity 6000.3.27f2 · URP (Mobile/PC RP assets from the Unity 6 template) · C# · Input System (UI module + PhysicsRaycaster) · uGUI · Android IL2CPP.

## Assemblies
| Assembly | Path | Notes |
|---|---|---|

| `ABCWonderworld.Editor` | `Scripts/Editor` | Generators (setup), validation report, builds. Editor only. |
| `ABCWonderworld.Tests.EditMode` / `.PlayMode` | `Tests/` | NUnit via Unity Test Framework 1.6. |

## Composition and flow
`Boot.unity` → `ApplicationBootstrapper` (DontDestroyOnLoad) builds, in order: ContentCatalog (Resources) → `JsonSaveRepository` → load save → `SettingsService`, `ProgressService`, `AdaptiveDifficulty`, `RewardService`, `SessionService` → `AudioService`, `SceneLoader`, `TouchInteractionService` (components on the boot object) → `GameFlowCoordinator`. These are published as the single composition root `GameServices.Current` (D-002). It validates content (errors logged, never fatal), starts a session, saves, and opens Home.

`GameFlowCoordinator` holds a `NavigationContext` (screen, world, letter, activity, case) and rejects navigation while `SceneLoader` is transitioning, so double taps cannot load twice. Failed loads fall back to Home. `SceneLoader` fades a full-screen cover that blocks input.

Scenes (generated by `SceneBuilder`): `Boot`, `Home`, `WorldMap`, `World_<id>` ×5, `Activity`, `AlphabetBook`. Each holds a camera, light, EventSystem and one controller (`Screens/*`) that builds data-driven content in `Start()`. `GameServices.EnsureBooted()` makes every scene runnable alone.

## Data pipeline
`Content/alphabet.json` → `ContentBuilder` → ScriptableObjects in `ScriptableObjects/` + `Resources/ContentCatalog.asset`.
`Tools/voice/build_voice_manifest.py` → `Content/voice_manifest.json` → TTS WAVs in `Audio/Voice/en/` → `AudioLibrary` (status per clip).
`LetterStrokeLibrary` → TracingDefinitions, `GlyphGraphic` (UI) and `GlyphMeshBuilder` (3D bodies).
Stable IDs: `letter_x`, `vocab_word`, `character_x`, `world_*`, `tracing_x_upper|lower`, `adventure_x`, `sticker_x`. Persisted data keys only on these.

## Rendering and performance notes
Procedural meshes are small (letter tube ≈ 3–6k verts). Materials are tinted copies of 3 base materials (`MaterialLibrary`), and instancing is enabled. One directional light with soft shadows at 30 m. Mobile RP: MSAA 4×, no HDR. Pictures are 256 px sprites, compressed. Not yet done: device profiling, LOD, pooling for balloons/confetti (the counts are small: ≤5 balloons, ≤40 confetti).

## Testing hooks
`ActivityBase.AutoPlay()` drives each activity through the same handlers as touch. `AutoPilot` (desktop player with `-abcw-autopilot`) plays the real flow and screenshots it. PlayMode tests run activities in the real Activity scene with a temp save folder (`ApplicationBootstrapper.SaveDirectoryOverride`).
